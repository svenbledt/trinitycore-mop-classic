# Phase 1 — Login, realm list and character screen: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A MoP Classic 5.5.4.70032 client started through Arctium logs in to this core, sees the realm list, and reaches an empty character screen.

**Architecture:**
- The servers run in Docker: MySQL 8.4, plus upstream's CI builder and runner images.
- Build-specific protocol data is generated by bun scripts in `tools/mop-re/`:
  - Opcodes come from an IDA export of the 70032 dump, with names from WowPacketParser.
  - DB2 metadata comes from WoWDBDefs.
- Hand-written changes are limited to `DB2Structure.h`, the auth SQL and the login-path packets. Each one cites its source.

**Tech Stack:**
- C++20 TrinityCore (CMake 3.24+, Ninja, Debian 13 GCC from the upstream image).
- bun with TypeScript, using `bun test`.
- IDAPython in the user's IDA Pro 9.4 GUI session, accessed through the IDA MCP.
- Docker Compose v5 and MySQL 8.4.

**Spec:** `docs/superpowers/specs/2026-10-08-phase1-login-realmlist-design.md`

- Pinned reference SHAs: WowPacketParser `9c0e672642b5aa6175bf7de1e76fad57d6dde477`, WoWDBDefs `e3df370` (resolve to the full SHA in Task 2).

## Review Focus

1. **The client sends an opcode the server doesn't know.** It must be logged and dropped, not crash or end the session. Pinned by the Catch2 test in Task 5 (`GetOpcodeArrayIndex` returns -1 for unknown groups) and by checking the e2e log in Task 10.
2. **Opcodes absent in 70032 but still referenced by upstream code** (void storage etc.) must never be sent to the client with a value that collides with a real 70032 opcode. Pinned in Task 5 by a test that every "absent" opcode maps to array index -1.
3. **A DB2 file whose layout hash doesn't match the generated metadata** must fail loudly at worldserver startup, naming the file, not misread silently. Pinned in Task 8 by checking the startup log for zero layout errors, and by the dump cross-check script.
4. **Re-baselining to a new client build** must be mechanical: the generators must be idempotent (running twice gives no diff). Pinned by the idempotency test in Task 5 (Step 2) and the second-run no-diff check in Task 7 (Step 4).
5. **An account logging in with a build the server doesn't know** (wrong build, missing auth key) must get a clean rejection in the logs, not an assert. Pinned by the Task 9 manual check that 4.4.2-only `build_auth_key` rows don't match a 70032 client.

```bash
set -euo pipefail
```

```bash
dist="/opt/tc/etc/${name}.conf.dist"
out="/opt/tc/etc/${name}.conf"

while IFS= read -r line; do
```

```ts
// src/wpp.ts
import type { OpcodeEntry } from "./types";

export function parseWppOpcodes(src: string): OpcodeEntry[] {
  const out: OpcodeEntry[] = [];
  const re = /\{\s*Opcode\.((CMSG|SMSG)_\w+)\s*,\s*(0x[0-9A-Fa-f]+)\s*\}/g;
  for (const m of src.matchAll(re))
    out.push({ name: m[1], value: parseInt(m[3], 16), dir: m[2] as "CMSG" | "SMSG" });
  return out;
}
```

### Task 3: Locate the 70032 opcode tables and export them (RE)

**Files:**
- Create: `docs/mop-port/re-notes.md`, `tools/mop-re/ida/export_opcodes.py`
- Output (not committed): `tools/mop-re/out/70032/opcodes.json`

**Interfaces:**
- Produces `out/70032/opcodes.json`, an array of objects with:
  - `dir`: `"CMSG"` or `"SMSG"`
  - `value`: number
  - `rva`: address of the handler (SMSG) or the packet constructor or serializer (CMSG), as an IDA EA hex string
  - `size_hint`: number or null; the struct size or vtable, if the registration exposes it

- [ ] **Step 1: Check the build and attach to the user's IDA session**

Check the dump version (Global Constraints). Then call `idb_list`. If the GUI session is listed, use `idb_open` with `mode: "prefer_gui"` and `input_path: "D:\\WoW\\World of Warcraft\\_classic_\\WowClassic_dump.exe"`. Call `server_health` and confirm the database is not `is_analyzing`. If auto-analysis is still running, stop and tell the user.

- [ ] **Step 2: Find SMSG dispatch using known value ranges**

WPP 5.5.3 SMSG groups are `0x2F` to `0x4F`, and 70032 is expected to be close. Search for immediate operands that look like `SMSG_AUTH_CHALLENGE` candidates:
- `insn_query` (or `find_bytes`) for `mov e?x, imm32` where `imm32 >> 16` is in `0x3E..0x45` and `imm32 & 0xFFFF == 0`.
- For each hit, `xrefs_to` its function, and `decompile` the containing function.

Look for a function that registers many opcode→handler pairs, with a long sequence of calls taking (table, opcode immediate, function pointer), or a large jump table indexed by `opcode - base`. Record the registration function's EA and its call pattern.

- [ ] **Step 3: Find CMSG construction**

Client→server packets are built by per-opcode constructors that write the opcode immediate into a packet header. Search for immediates in the CMSG groups (WPP 5.5.3: `0x2D..0x3A`) stored into a struct field, and find the common callee that sends packets (it xrefs the socket send). Record the pattern.

- [ ] **Step 4: Verify with two anchors**

1. `SMSG_AUTH_CHALLENGE` and `SMSG_ENTER_ENCRYPTED_MODE` handlers are reached before encryption is enabled. Their handlers xref the code that sets up the session cipher (look for `HMAC`/`SHA512`/`AES` constants such as the SHA-512 IV `0x6A09E667F3BCC908`, or calls into the crypto library).
2. The `CMSG_AUTH_SESSION` constructor writes a 32-byte `LocalChallenge` and a 24-byte `Digest` (see `AuthenticationPackets.cpp`'s `AuthSession::Read`).

Write down the 70032 values found for these four opcodes.

- [ ] **Step 6: Write `tools/mop-re/ida/export_opcodes.py`** using the patterns from Steps 2–3

Skeleton (the pattern-specific parts follow `re-notes.md`):
```python
# Run inside the user's IDA session (via MCP py-eval or File > Script file). Read-only.
import json, idautils, idc, ida_bytes, ida_funcs

SMSG_REG_FUNC = 0x0  # from re-notes.md
SENDER_FUNC   = 0x0  # from re-notes.md
OUT = r"F:\WorkDir\trinitycore-mop-classic\tools\mop-re\out\70032\opcodes.json"

def operand_imm_before_call(call_ea, reg_names, max_back=12):
    ea = call_ea
    for _ in range(max_back):
        ea = idc.prev_head(ea)
        if idc.print_insn_mnem(ea) == "mov" and idc.print_operand(ea, 0) in reg_names \
           and idc.get_operand_type(ea, 1) == idc.o_imm:
            return idc.get_operand_value(ea, 1)
    return None

entries = []
for xref in idautils.CodeRefsTo(SMSG_REG_FUNC, 0):
    op = operand_imm_before_call(xref, ("edx", "rdx"))
    handler = operand_imm_before_call(xref, ("r8", "r8d"))
    if op is not None:
        entries.append({"dir": "SMSG", "value": op, "rva": hex(handler or 0), "size_hint": None})
for xref in idautils.CodeRefsTo(SENDER_FUNC, 0):
```

### Task 4: Name matching (client values ↔ WPP names)

**Files:**
- Create: `tools/mop-re/src/match.ts`, `tools/mop-re/test/match.test.ts`, `tools/mop-re/overrides/70032.json`

**Interfaces:**
- Consumes: `OpcodeEntry`, `group` and `index` (Task 2), and `opcodes.json` (Task 3).
- Produces:
  - `interface ClientOpcode { dir: Direction; value: number; rva: string }`
  - `interface Match { name: string; value: number; dir: Direction; confidence: "high" | "low" | "override" }`
  - `matchOpcodes(wpp: OpcodeEntry[], client: ClientOpcode[], overrides: Record<string, number>): { matched: Match[]; unmatchedClient: ClientOpcode[]; absent: OpcodeEntry[] }`
  - `renderReport(r): string` (markdown)

The algorithm, per direction:
1. Map groups by rank. Take the sorted distinct groups of WPP and of the client. If the counts are equal, map them positionally. If not, throw an error listing both group lists; the user then adds `"groupMap"` to the overrides.
2. Within a mapped group pair, sort both sides by index.
   - If the counts are equal, match them positionally. Confidence is `high` when every index delta is constant, otherwise `low`.
   - If the client side has more entries, match positionally by index while the deltas agree. Remaining client entries become `unmatchedClient`, and WPP entries left without a counterpart become `absent`. All matches in that group are `low`.
3. Overrides (name → value) win over everything and get confidence `override`.

```ts
import { type Direction, type OpcodeEntry, group, index } from "./types";

export interface ClientOpcode { dir: Direction; value: number; rva: string }
export interface Match { name: string; value: number; dir: Direction; confidence: "high" | "low" | "override" }
export interface MatchResult { matched: Match[]; unmatchedClient: ClientOpcode[]; absent: OpcodeEntry[] }

export function matchOpcodes(wpp: OpcodeEntry[], client: ClientOpcode[], overrides: Record<string, number>): MatchResult {
  const res: MatchResult = { matched: [], unmatchedClient: [], absent: [] };
  const overriddenValues = new Set(Object.values(overrides));
  for (const dir of ["CMSG", "SMSG"] as Direction[]) {
    const w = wpp.filter(e => e.dir === dir && !(e.name in overrides));
    const c = client.filter(e => e.dir === dir && !overriddenValues.has(e.value));
    const wg = [...new Set(w.map(e => group(e.value)))].sort((a, b) => a - b);
    const cg = [...new Set(c.map(e => group(e.value)))].sort((a, b) => a - b);
    if (wg.length === 0) { res.unmatchedClient.push(...c); }
    else if (wg.length !== cg.length)
      throw new Error(`${dir} group count differs: wpp [${wg.map(g => g.toString(16))}] vs client [${cg.map(g => g.toString(16))}]`);
    if (wg.length) wg.forEach((g, i) => {
      const ws = w.filter(e => group(e.value) === g).sort((a, b) => index(a.value) - index(b.value));
      const cs = c.filter(e => group(e.value) === cg[i]).sort((a, b) => index(a.value) - index(b.value));
      const n = Math.min(ws.length, cs.length);
      const deltas = new Set<number>();
      for (let k = 0; k < n; k++) deltas.add(index(cs[k].value) - index(ws[k].value));
      const confidence = ws.length === cs.length && deltas.size === 1 && deltas.has(0) ? "high" : "low";
      for (let k = 0; k < n; k++) res.matched.push({ name: ws[k].name, value: cs[k].value, dir, confidence });
      res.absent.push(...ws.slice(n));
      res.unmatchedClient.push(...cs.slice(n));
    });
    for (const [name, value] of Object.entries(overrides))
      if (name.startsWith(dir)) res.matched.push({ name, value, dir, confidence: "override" });
  }
  res.matched.sort((a, b) => a.dir.localeCompare(b.dir) || a.value - b.value);
  return res;
}

export function renderReport(r: MatchResult): string {
  const line = (m: Match) => `| ${m.name} | 0x${m.value.toString(16).toUpperCase()} | ${m.confidence} |`;
  return [
    `# Opcode match report`, ``,
    `matched: ${r.matched.length} (low: ${r.matched.filter(m => m.confidence === "low").length}), unmatched client: ${r.unmatchedClient.length}, absent in client: ${r.absent.length}`, ``,
    `## Low confidence`, `| name | value | confidence |`, `|---|---|---|`, ...r.matched.filter(m => m.confidence === "low").map(line), ``,
    `## Unmatched client values`, ...r.unmatchedClient.map(c => `- ${c.dir} 0x${c.value.toString(16).toUpperCase()} (${c.rva})`), ``,
    `## Absent in client (WPP names without a 70032 value)`, ...r.absent.map(a => `- ${a.name}`),
  ].join("\n");
}
```

The first test expects `high` for equal-size groups that differ only by group number (the index delta is 0). The second expects `low` because the index deltas are not constant (0 and 2). The implementation matches both.

```ts
import { type Direction, group, index } from "./types";
import type { MatchResult } from "./match";

const hex6 = (v: number) => "0x" + v.toString(16).toUpperCase().padStart(6, "0");
const pad = (s: string, col: number) => s + " ".repeat(Math.max(1, col - s.length));
const SENTINEL: Record<Direction, number> = { CMSG: 0xff0000, SMSG: 0xfe0000 };
const ENUM: Record<Direction, string> = { CMSG: "OpcodeClient", SMSG: "OpcodeServer" };

function enumBody(r: MatchResult, dir: Direction, build: string): string {
  const live = r.matched.filter(m => m.dir === dir).sort((a, b) => a.name.localeCompare(b.name));
  const gone = r.absent.filter(a => a.dir === dir).sort((a, b) => a.name.localeCompare(b.name));
  const lines = live.map(m => pad(`    ${m.name}`, 55) + `= ${hex6(m.value)},` + (m.confidence === "low" ? " // TODO(verify): low-confidence match" : ""));
  if (gone.length) {
    lines.push("", `    // Not present in client ${build}; kept so upstream code compiles. Never registered, never valid.`);
    gone.forEach((a, i) => lines.push(pad(`    ${a.name}`, 55) + `= ${hex6(SENTINEL[dir] | i)},`));
  }
  return lines.join("\n");
}

function indexBlock(r: MatchResult, dir: Direction): { num: number; cases: string } {
  const sizes = new Map<number, number>();
  for (const m of r.matched.filter(m => m.dir === dir))
    sizes.set(group(m.value), Math.max(sizes.get(group(m.value)) ?? 0, index(m.value) + 1));
  let off = 0; const cases: string[] = [];
  for (const g of [...sizes.keys()].sort((a, b) => a - b)) {
    const n = sizes.get(g)!;
    cases.push(`        case 0x${g.toString(16).toUpperCase().padStart(2, "0")}: return idInGroup < ${n} ? idInGroup + ${off} : -1;`);
    off += n;
  }
  return { num: off, cases: cases.join("\n") };
}

export function rewriteOpcodesH(src: string, r: MatchResult, build: string): string {
  let out = src;
  for (const dir of ["CMSG", "SMSG"] as Direction[]) {
    const e = ENUM[dir];
    out = out.replace(new RegExp(`(enum ${e} : uint32\\n\\{\\n)[\\s\\S]*?(\\n\\};)`), `$1${enumBody(r, dir, build)}$2`);
    const { num, cases } = indexBlock(r, dir);
    out = out.replace(new RegExp(`NUM_${dir}_OPCODES = \\d+;`), `NUM_${dir}_OPCODES = ${num};`);
    out = out.replace(new RegExp(`(GetOpcodeArrayIndex\\(${e} opcode\\)[\\s\\S]*?switch \\(opcode >> 16\\)\\n    \\{\\n)[\\s\\S]*?(\\n        default: return -1;)`), `$1${cases}$2`);
  }
  const banner = `// Generated for client build ${build} by tools/mop-re (names: WowPacketParser). Do not edit values by hand.\n`;
  out = out.replace(/\/\/ Generated for client build .*\n/, "");
  return out.replace(/enum OpcodeClient : uint32/, banner + "enum OpcodeClient : uint32");
}

export function rewriteOpcodesCpp(src: string, r: MatchResult): string {
  const absent = new Set(r.absent.map(a => a.name));
  let lines = src.split("\n").filter(l => {
    const m = l.match(/DEFINE_(?:SERVER_OPCODE_)?HANDLER\((\w+),/);
    return !(m && absent.has(m[1]));
  });
  const present = new Set(lines.map(l => l.match(/DEFINE_(?:SERVER_OPCODE_)?HANDLER\((\w+),/)?.[1]).filter(Boolean) as string[]);
  for (const m of r.matched) {
    if (present.has(m.name)) continue;
    const line = m.dir === "CMSG"
      ? pad(`    DEFINE_HANDLER(${m.name},`, 76) + "STATUS_UNHANDLED, PROCESS_INPLACE,      &WorldSession::Handle_NULL);"
      : pad(`    DEFINE_SERVER_OPCODE_HANDLER(${m.name},`, 79) + "STATUS_UNHANDLED,    CONNECTION_TYPE_DEFAULT);";
    const macro = m.dir === "CMSG" ? "DEFINE_HANDLER(" : "DEFINE_SERVER_OPCODE_HANDLER(";
    const idx = lines.findIndex(l => l.includes(macro) && (l.match(/\((\w+),/)?.[1] ?? "") > m.name);
    const last = lines.map((l, i) => (l.includes(macro) ? i : -1)).filter(i => i >= 0).pop()!;
    lines.splice(idx >= 0 ? idx : last + 1, 0, line);
  }
  return lines.join("\n");
}

if (import.meta.main) {
  const [build, root] = Bun.argv.slice(2);
  const r = await Bun.file(`${import.meta.dir}/../out/${build}/match.json`).json();
  const hp = `${root}/src/server/game/Server/Protocol/Opcodes.h`, cp = `${root}/src/server/game/Server/Protocol/Opcodes.cpp`;

  await Bun.write(cp, rewriteOpcodesCpp(await Bun.file(cp).text(), r));
}
```

```ts
export interface DbdColumn { type: "int" | "float" | "string" | "locstring"; foreign?: string; name: string; verified: boolean }
export interface DbdField { name: string; size?: 8 | 16 | 32 | 64; unsigned: boolean; arrayLen: number; isId: boolean; isRelation: boolean; noninline: boolean; type: DbdColumn["type"] }
export interface DbdBuild { layoutHashes: string[]; fields: DbdField[] }

const ver = (b: string) => b.split(".").map(Number);
const cmp = (a: number[], b: number[]) => { for (let i = 0; i < 4; i++) if (a[i] !== b[i]) return a[i] - b[i]; return 0; };
const specMatches = (spec: string, build: string) => {
  if (spec.includes("-")) { const [lo, hi] = spec.split("-"); return cmp(ver(build), ver(lo)) >= 0 && cmp(ver(build), ver(hi)) <= 0; }
  return spec === build;
};

export function parseDbd(src: string) {
  const lines = src.split(/\r?\n/);
  const columns = new Map<string, DbdColumn>();
  let i = 0;
  if (lines[0].trim() === "COLUMNS") {
    for (i = 1; i < lines.length && lines[i].trim() !== ""; i++) {
      const m = lines[i].match(/^(\w+)(?:<(\w+)::(\w+)>)?\s+(\w+?)(\?)?(\s*\/\/.*)?$/);
      if (m) columns.set(m[4], { type: m[1] as DbdColumn["type"], foreign: m[2] ? `${m[2]}::${m[3]}` : undefined, name: m[4], verified: !m[5] });
    }
  }
  const builds: { specs: string[]; block: DbdBuild }[] = [];
  let cur: { specs: string[]; block: DbdBuild } | null = null;
  for (; i <= lines.length; i++) {
    const l = (lines[i] ?? "").trim();
    if (l === "") { if (cur && cur.block.fields.length) builds.push(cur); cur = null; continue; }
    cur ??= { specs: [], block: { layoutHashes: [], fields: [] } };
    if (l.startsWith("LAYOUT ")) cur.block.layoutHashes.push(...l.slice(7).split(",").map(s => s.trim().toUpperCase()));
    else if (l.startsWith("BUILD ")) cur.specs.push(...l.slice(6).split(",").map(s => s.trim()));
    else if (l.startsWith("COMMENT")) continue;
    else {
      const m = l.match(/^(?:\$([\w,]+)\$)?(\w+)(?:<(u?)(\d+)>)?(?:\[(\d+)\])?/);
      if (!m) continue;
      const anns = (m[1] ?? "").split(",");
      const col = columns.get(m[2]);
      cur.block.fields.push({
        name: m[2], size: m[4] ? (Number(m[4]) as 8 | 16 | 32 | 64) : undefined, unsigned: m[3] === "u",
        arrayLen: m[5] ? Number(m[5]) : 1, isId: anns.includes("id"), isRelation: anns.includes("relation"),
        noninline: anns.includes("noninline"), type: col?.type ?? "int",
      });
    }
  }
  return { columns, builds };
}

export function selectBuild(p: ReturnType<typeof parseDbd>, build: string): DbdBuild | null {
  return p.builds.find(b => b.specs.some(s => specMatches(s, build)))?.block ?? null;
}
```

```ts
const ft = (f: DbdField) => f.type === "float" ? "FT_FLOAT" : f.type === "locstring" ? "FT_STRING"
  : f.type === "string" ? "FT_STRING_NOT_LOCALIZED" : ({ 8: "FT_BYTE", 16: "FT_SHORT", 32: "FT_INT", 64: "FT_LONG" } as const)[f.size ?? 32];
const signed = (f: DbdField) => (f.type === "int" ? !f.unsigned : true);
const inMeta = (f: DbdField) => !f.noninline && !f.isRelation;

export function emitMeta(table: string, fdid: number, b: DbdBuild, parentIndex: number): string {
  const fields = b.fields.filter(inMeta);
  const idIdx = b.fields.find(f => f.isId)?.noninline ? -1 : fields.findIndex(f => f.isId);
  const body = fields.map(f => `        { ${ft(f)}, ${f.arrayLen}, ${signed(f)} },`).join("\n");
  return `struct ${table}Meta\n{\n    static constexpr DB2MetaField Fields[${fields.length}] =\n    {\n${body}\n    };\n\n` +
    `    static constexpr DB2Meta Instance{ ${fdid}, ${idIdx}, ${fields.length}, ${fields.length}, 0x${b.layoutHashes[0]}, Fields, ${parentIndex} };\n};`;
}

export function emitLoadInfo(table: string, b: DbdBuild, _cols: Map<string, DbdColumn>): string {
  const lines: string[] = [];
  for (const f of b.fields) {
    const sgn = f.type === "int" ? !f.unsigned : false;
    if (f.arrayLen === 1) lines.push(`        { ${sgn}, ${ft(f)}, "${f.name}" },`);
    else for (let k = 1; k <= f.arrayLen; k++) lines.push(`        { ${sgn}, ${ft(f)}, "${f.name}${k}" },`);
  }
  return `struct ${table}LoadInfo\n{\n    static constexpr DB2FieldMeta Fields[${lines.length}] =\n    {\n${lines.join("\n")}\n    };\n\n` +
    `    static constexpr DB2LoadInfo Instance{ Fields, ${lines.length}, &${table}Meta::Instance, HOTFIX_SEL_${snake(table)} };\n};`;
}

export const snake = (t: string) => t.replace(/([a-z0-9])([A-Z])/g, "$1_$2").replace(/([A-Z])([A-Z][a-z])/g, "$1_$2").toUpperCase();
```
